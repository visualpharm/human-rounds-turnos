# AGENTS.md — Human Rounds

An open-source appointment engine for public health networks, born at
**Hospital de Pinamar + CAPS** (Buenos Aires province, Argentina), which runs
the live reference deployment. [CLAUDE.md](CLAUDE.md) is the canonical
reference — the invariants and the "Where the detail lives" table pointing at
every `docs/architecture/*.md`. Read it first; this file says only what an
agent cannot infer and points at the scoped files:
`app/admin_panel/AGENTS.md`, `app/patient_web/AGENTS.md`, `app/modules/turnos/AGENTS.md`,
`static/platform/AGENTS.md`.

## Where things live

- `app/asgi_main.py` (`python3 -m app`) is the only entrypoint and `app/main.py` the FastAPI composition; all application code is in `app/`, the tests in `tests/` (docs/LAYOUT.md). The legacy topology (`server.py`, `core/routing.py`, `legacy_shim.py`, every module's old `handle()` transport) is deleted — never wire anything back through it.
- `app/modules/<id>/` own their surface (`turnos`, `intake`, `chat`); `app/admin_panel/` is the staff console; `app/patient_web/` the public site; `static/platform/` the browser ESM; `packs/` the layered data, read only via `sitedata.path(fname)`.
- Decision log: a new entry goes at the end of `docs/decisions/<YYYY-MM>.md` for today's month, then `python3 scripts/decisions_index.py --write`; `docs/decisions.md` is the rules and the index, never an entry.
- `docs/architecture/*.md` per area, `docs/solutions/INDEX.md` for solved problems, `docs/pinamar/` and the private `humanrounds-pinamar` repo for the reference deployment.

## Run and test

- `PORT=7700 TURNOS_ASGI=1 python3 -m app` → http://127.0.0.1:7700. Two loopback Postgres lanes: `DATABASE_URL` (app, Homebrew 5432) and `TEST_DATABASE_URL` (tests, HSI docker 5433).
- Tests go through the managed executor, which injects the DB lanes from the vault (no checkout `.env`): `python3 scripts/turnos_managed_exec.py --profile backend-full` (backend), `--profile backend-focused --test tests/test_x.py` (one file), `--profile e2e-<area>-asgi` (one browser suite), `--profile local-ci-asgi` (the whole gate, ~25 min on 16 cores, measured 2026-10-26; `~/.claude/bin/local-ci` runs `local-ci`). Frontend: `node --test tests/*.test.mjs`; inside Claude Code the credential hook blocks globs, so use `bash scripts/pre-commit.sh` (frontend + Accounts + routes). Always `discover -s tests` for a raw unittest run: `unittest tests.test_x` misses `tests/` on `sys.path`, and `-s test` (the old name) finds the stdlib's own suite.
- Never start a long pre-commit or local-ci in the background without a timeout for the whole run; long shell runners source `scripts/orphan_guard.sh` so their children die with them.
- `python3 scripts/local-logins.py` seeds the two local logins (admin `admin-local` → `/admin`, patient `36555444` → `/account`) and prints one JSON line; idempotent, `--rotate` regenerates, refuses any non-localhost database.
- `package.json` must not declare `"type": "module"` yet: canonical ESM is `.mjs`, the remaining classic files are UMD/CommonJS IIFEs loaded with `require()`.

## Invariants no model can infer

1. Patient-facing copy is Spanish with i18n fallback; documentation, code and admin labels are English.
2. Walk-in never offers appointments; the sole exception is `apertura_mismo_dia`.
3. A patient's booking limit is a number resolved doctor → service → site (`booking_limits.py`), enforced only on the patient's own POST.
4. Nothing identifying leaves for an external AI without `app/core/pii.py`; the referral image/PDF is the one deliberate exception.
5. The brand is "Human Rounds", never "Sana"; the public site claims no measured outcomes.
6. `pinamar.humanrounds.org` and `demo.humanrounds.org` both ship from `main` through the Coolify webhook — leave it alone; there is no CDN in front of either.
7. Locales other than `es`/`en` are generated by `scripts/translate_locales.py`; fix the Spanish and re-run, never hand-edit them.

## Admin UI

**Divider audit hook (MANDATORY):** whenever HTML or CSS is added or edited,
inspect every `<hr>`, separator element, `border-top`, and `border-bottom` in
the touched surface before finishing. The full contract and the
simplification evaluator live in `app/admin_panel/AGENTS.md`.

## Model routing

Execution defaults to GLM Flash (GLM 5.3 for complex slices); Codex Astra is the
fallback when GLM is rate-limited. Fable low or Opus 5 low does planning and the
final independent review. Never claim a model ran unless the runtime confirms it.
