## 2026-10-24 · The whole e2e suite runs on @playwright/test
Decided: every browser e2e file (78 files, 615 tests) is a `test/e2e/<name>.spec.mjs` run by
@playwright/test 1.63.0 (`playwright.config.mjs`); `npm run e2e`, `npm run e2e:dev`, `scripts/ci_local.sh`
(and so `local-ci` / `local-ci-asgi`), the `e2e` job of `.gitlab-ci.yml` and every narrow `e2e-*-asgi`
profile of `scripts/turnos_managed_exec.py` run it; the `node:test` copies are deleted, not kept beside it.
Gate shape: one worker per core (the GitLab `e2e` job caps it at `PW_WORKERS=4`, the shape measured on a 4-core container beside a looping backend suite), `retries: 2`, `trace: on-first-retry`, list + html reporters, and a test
that fails once and passes on a retry still FAILS the run (`PW_FAIL_ON_FLAKY=0` is the opt-out), so the gate is
exactly as strict as the `node --test` one while every failed attempt keeps its screenshot and page snapshot and the first retry carries the trace. The harness
(`test/e2e/lib/harness.mjs`) stays the only place that starts the app and the database; the fixtures
(`test/e2e/lib/fixtures.mjs`) run one app per FILE (worker-scoped, keyed by a unique `dbName` in
`test.use({ appOptions })`), with `launchApp`, `newContext`, `serve`, `cleanup`, `holdGate`, `holdsFor`,
`saveShot`; `test/e2e-spec-isolation.test.mjs` pins the unique `dbName`, the absence of `waitForTimeout`
and of `node:test`/`node:assert` in the specs.
Why: Product owner, via the maintainer (Teams 24.10 16:18 UTC): "we are now moving all the tests to playwright test — on a
separate branch — and you decide on the result. This is the standard". The measured comparison is in the MR.
Agent calls (reversible): behaviour kept one to one — same titles and order, same race guards (a held route, a
point-in-time snapshot) and pins; fixed sleeps became retrying expects, events or a `holdsFor` window; the
context sends no `Accept-Language` (as the library's `browser.newPage()` did; Playwright Test's default
`en-US` turned every multi-language page English); files that need no server are `hermetic`; the 8
always-skipped «404s in legacy mode» tests of `admin-screen` (`ASGI` was a constant `true`) are gone;
`hsi-disabled` runs its 24 sub-tests as 24 `test.step`s of one test; the upload race that made booking,
patient-portal and listing-delayed float (a file chosen while the order step re-renders was lost) is not
hidden by a re-delivering helper — the tests choose the file once, as before, and the product was fixed
(cabc540d).
Undo: revert the MR — the `node:test` files, `npm run e2e` and the profiles come back (no application code or
data changed).
By: Product owner (the move to Playwright Test), agent (the fixtures, the files, the gate shape).
Source: `playwright.config.mjs`, `test/e2e/lib/fixtures.mjs`, `test/e2e/*.spec.mjs`,
`test/e2e-spec-isolation.test.mjs`, `scripts/turnos_managed_exec.py`, `scripts/ci_local.sh`, `.gitlab-ci.yml`.
