## 2026-08-05 · Tier 4 re-platform: FastAPI, Alembic, Postgres queue, fingerprinting
Decided: re-platform the backend strangler-style onto FastAPI/uvicorn (in-process reverse proxy, one public port, zero Coolify/Traefik changes per slice), library auth (pyotp + webauthn + itsdangerous, with migration history for existing sessions/passkeys), Jinja2, Alembic, procrastinate for the background tasks, static content-hash fingerprinting replacing manual `?v=`. · Why: binding design doc; includes a risk/decision register for the product owner (passkey migration, demo soak window, procrastinate vs pgqueuer, Sentry). · Rejected: pgqueuer — listed as an open alternative in the design's decision register; procrastinate is what shipped · Undo: not recorded · By: agent
Source: commit `cf38a865`, 2026-08-05; [docs/roadmap/tier4-replatform-design.md](../roadmap/tier4-replatform-design.md).

## 2026-08-05 · No CDN in front of either site
Decided: no CDN in front of `pinamar.humanrounds.org` or `demo.humanrounds.org`; page speed is won by making FEWER requests, not by hoping an edge absorbs them. Verified live: stdlib server through Coolify's proxy, no `cf-ray`, no `cf-cache-status`. · Why: Product owner decided not to put Cloudflare in front (the old `?v=` ritual had been written for a Cloudflare config that no longer existed). · Rejected: Cloudflare · Undo: not recorded · By: Product owner
Source: commit `4c2e9bb0`, 2026-08-05; CLAUDE.md (Deploy invariants).

## 2026-08-06 · Alembic becomes the sole schema authority
Decided: cutover to Alembic (baseline no-op, stamp vs upgrade); the app classifies the database at boot and runs pending migrations itself, so there is no separate migrate step. Later hardened: numbered `migrations/` frozen as a one-time bridge, multi-head prevention guard, every new schema change ships `_SCHEMA_SQL` + a forward revision. · Why: part of the Tier 4 design — schema migrations at boot. · Rejected: not recorded · Undo: not recorded · By: agent
Source: commits `387c8147` (cutover, 2026-08-06) and `ccbc4820` (multi-head guard, 2026-09-13); `test/test_alembic_cutover.py`.

## 2026-08-27 · Legacy topology deleted; `asgi_main.py` is the only entrypoint
Decided: retire the executable legacy topology entirely (`server.py`, legacy transports/shims, every module's old `handle(handler, method)`); `asgi_main.py` boots the FastAPI composition in `app.py` and `TURNOS_ASGI=1` is mandatory. Deletion is pinned by a test, not just documented. · Why: final wave of the native migration; the strangler phase ends, dark-mode legacy goes away. · Rejected: keeping the legacy path dormant as a fallback · Undo: not recorded · By: agent
Source: commit `3e886141`, 2026-08-27; CLAUDE.md (Code-shape invariants).
