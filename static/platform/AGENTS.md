# static/platform/ — browser ESM for the patient site and the panel

- One formatter per datum: `format.mjs` mirrored by `app/core/format.py`, parity-tested. Phones `telTexto`/`tel_text`, people `nombre`/`person_name` (rewrites all-caps and all-lowercase only, leaves mixed names alone). Consumers delegate, never reimplement.
- One table engine each: `admin-table.mjs` (`crear`, `columnas`) for every panel table, `listing.mjs` for every patient-site table.
- A new control copies the existing control that already does the same job — class, size, colour, icon, wording — and differs only for a stated reason, keeping colour, terms and icon even then. Add the pair to `tests/ui-evals.test.mjs` eval 3 whenever you build a second instance.
- Link affordance per theme: `pinamar` colours links `--accent` at rest, brighter `--accent-hover` on hover, no underline, `--link-visited`; `humanrounds` renders ink text with a faint `--link-underline` that strengthens on hover. A link never declares `font-weight`. The underline lives only in `tokens.css` and the base `a{}` rule in `human-rounds.css`; no other file sets `text-decoration:underline` or `border-bottom` as a link affordance (`.claude/hooks/link-underline-guard.py`, eval 8).
- A client-rendered string is `T(key, vars, "<castellano>")` with the Spanish fallback; never hold translated text in a module-level constant — compute it inside the render, after the native i18n import resolves.
- Canonical ESM is `.mjs`; the classic UMD/CommonJS files are loaded with `require()` by `node --test`, so `package.json` stays without `"type": "module"` until they migrate in bounded slices.
- Storybook (`npm run storybook`, http://127.0.0.1:7500, `@storybook/html-vite`): a story imports the real render module (`calendar-grid.mjs`, `format.mjs`, `tiles.mjs`, `week.mjs`) or calls a real `window.Sana*` render function, never reimplemented markup. A panel screen becomes story-able only when its render lives in a module that owns its own `css` string (the `calendar-grid.mjs` shape) — extracting the module is the work.
- Served first-party JS/CSS is content-hash fingerprinted (`app/core/static_fingerprint.py`): platform assets via `MIGRATED`, module assets via manifest `{path, fingerprint: true}` rendered through `module_url()` / `module_static()`.
- `admin-hsi.mjs` is inert until mounted, owns its reads, mutations and listeners per mount, and disposes on page exit.
